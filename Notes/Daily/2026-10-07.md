## 🛠️ Pekerjaan yang Dilakukan

### 1. Investigasi & Solusi Root Cause Jendela Ganda
- **Penyebab**: Aplikasi desktop dibundel sebagai file executable tunggal (`SintelisUtility.exe`). Saat memanggil script python (`export_tablo_excel.py` / `export_dinasan_excel.py`), sistem memanggil `sys.executable`. Tanpa adanya dispatcher argumen di awal `main()`, executable memproses peluncuran WebView baru secara default, sehingga membuka GUI kedua.
- **Solusi**:
  - Menambahkan *CLI Script Dispatcher* di baris awal `main()` pada `run_desktop_webview.py`.
  - Jika executable menerima argumen `--run-script` atau berakhiran `.py`, eksekusi dialihkan langsung ke `runpy.run_path()` dan langsung keluar (`sys.exit(0)`) tanpa pernah memanggil `webview.create_window()`.
  - Menambahkan flag `creationflags=0x08000000` (`CREATE_NO_WINDOW`) pada seluruh pemanggilan `subprocess.run` dan `subprocess.Popen` di `run_desktop_webview.py` dan `pipeline_runner.py` agar tidak memunculkan console window berkedip.

### 3. Investigasi & Solusi Ukuran File Membengkak (Recursive Bundling)
- **Penyebab**: Di file `build_exe.spec`, konfigurasi `datas` memaketkan seluruh isi direktori `dist/`. Karena PyInstaller juga menaruh output binary `SintelisUtility.exe` di folder `dist/`, maka saat kompilasi dijalankan berulang, file `.exe` lama ikut dibungkus ke dalam file `.exe` yang baru (*recursive bundling*), menyebabkan ukuran melonjak menjadi 1.11 GB.
- **Solusi**:
  - Memperbarui `build_exe.spec` untuk secara otomatis menghapus file `.exe` lama di folder `dist/` sebelum kompilasi, serta menyaring `datas` hanya untuk berkas frontend web (`.html`, `.js`, `.css`, `.svg`, `.json`).
  - Menambahkan langkah pembersihan otomatis di skrip deploy server.
  - Hasil: Ukuran biner berhasil dipangkas drastis dari **1.11 GB (1116 MB)** kembali menjadi **179.27 MB** (ramping dan normal).

### 4. Investigasi & Solusi Galat `No module named 'cryptography'` pada Ekspor Excel
- **Penyebab**: Saat pengguna mengekspor Tablo/Jadwal dengan folder kustom, `scheduler.py` memproses berkas PDF menggunakan pustaka `pypdf`/`pdfplumber`. Pustaka `pypdf` membutuhkan modul `cryptography` untuk mendekripsi/membaca struktur dokumen PDF. Namun pada `build_exe.spec`, `cryptography` sebelumnya dimasukkan ke dalam daftar `excludes` sehingga hilang saat dibundel.
- **Solusi**:
  - Menghapus `cryptography` dari daftar `excludes` di `build_exe.spec`.
  - Menambahkan `cryptography` dan `pypdf._crypt_providers._cryptography` ke dalam `hiddenimports`.
  - Menambahkan flag `--run-script` dan `CREATE_NO_WINDOW` pada pemanggilan sub-proses di `export_tablo_excel.py` dan `replace_export_photo.py`.

### 9. Penyimpanan Permanen Profil Preset Pegawai di AppData & Fitur Cadangkan/Pulihkan JSON (Rilis v1.5.7)
- **Keluhan Pengguna**: *"kenapa profil preset selalu hilang setiap update? aku sudah update preset 2025, tp setiap update, profil preset selalu hilang"*.
- **Investigasi & Akar Masalah (Root Cause)**:
  1. *Penyimpanan Volatil di Temp PyInstaller*: Pada versi sebelum v1.5.6, skrip menyimpan `employee_presets.json` dan `daftar_pegawai.json` ke folder `ENGINE_DIR` yang berada di dalam `sys._MEIPASS` (`C:\Users\<user>\AppData\Local\Temp\_MEIxxxxxx`). Direktori sementara ini otomatis dihapus oleh Windows saat aplikasi ditutup atau saat pembaruan diekstrak. Saat versi baru dijalankan, PyInstaller membuat folder `_MEI...` baru dengan berkas template bawaan server, melenyapkan seluruh preset yang telah diedit/ditambahkan pengguna.
  2. *Ketiadaan Inisialisasi Otomatis (Seeding)*: Direktori persisten pengguna `%LOCALAPPDATA%\SintelisUtility` tidak pernah diisi otomatis saat aplikasi pertama kali dijalankan.
  3. *Ketiadaan Fitur Pencadangan (Backup/Restore)*: Tidak ada sarana bagi pengguna untuk mengekspor atau memulihkan preset dari/ke berkas `.json` mandiri.
- **Implementasi Solusi Permanen**:
  1. **Penyimpanan Permanen `%LOCALAPPDATA%\SintelisUtility`**:
     - Seluruh logika baca (`_handle_timemark_pegawai_get`, `get_active_pegawai_config`) dan tulis (`_handle_timemark_pegawai_post`, `_handle_timemark_set_active_preset`) dipusatkan 100% ke `%LOCALAPPDATA%\SintelisUtility\employee_presets.json` dan `daftar_pegawai.json`.
     - Data di direktori ini dijamin bertahan permanen melewati update aplikasi, restart Windows, maupun instalasi ulang.
  2. **Inisialisasi Otomatis (`_init_persistent_storage()`)**:
     - Saat startup, sistem mengecek apakah berkas preset sudah ada di AppData. Jika belum, konfigurasi bawaan (termasuk preset `2025` dengan KUPT S. SLAMET RIYADI dan `2025 BARU`) disalin otomatis. Jika sudah ada, sistem tidak pernah menimpanya sehingga editan pengguna aman 100%.
  3. **Penulisan Berkas Atomik (`_atomic_write_json`)**:
     - Berkas ditulis ke ekstensi `.tmp` lalu di-replace seketika untuk mencegah berkas corrupt saat aplikasi ditutup paksa.
  4. **Fitur Cadangkan (Backup) & Pulihkan (Restore) JSON di UI**:
     - Menambahkan tombol native `📤 Cadangkan` (ekspor ke file JSON) dan `📥 Pulihkan` (impor dari file JSON) pada header `EmployeeManagerPanel.jsx`.
     - Didukung endpoint backend `/api/timemark/export-presets` dan `/api/timemark/import-presets` dengan dialog penyimpanan native Windows OS.
  5. **Integrasi Mesin Dokumen**:
     - `employee_manager.py` dan `export_dinasan_excel.py` otomatis memeriksa `%LOCALAPPDATA%\SintelisUtility\daftar_pegawai.json` sebagai rujukan utama.
  6. **Rilis Server Publik v1.5.7**:
     - Mengikuti 10 langkah SOP `update_app.md` secara ketat.
     - Build frontend Vite sukses (`0 error`).
     - Kompilasi PyInstaller clean di PC Server Bogor dan validasi batas guardrail biner.
