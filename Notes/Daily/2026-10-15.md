## 🛠️ Pekerjaan yang Dilakukan

### 1. Engine Backend: `date_changer_engine.py`
- **Arsitektur Penggantian Tanggal**:
  - `parse_date_flexible(date_str)`: Mengurai berbagai format tanggal input (ISO `YYYY-MM-DD`, DMY `DD-MM-YYYY`, dan teks bulan Indonesia).
  - `get_new_filename(orig_filename, new_date)`: Menghasilkan nama file baru dengan menyelaraskan pola penamaan dari P3-STE download (`_correct_filename_date` & `parseDate`):
    - Format prefix: `09-02-2025_PERAWATAN...pdf` ➔ `15-03-2026_PERAWATAN...pdf`.
    - Format suffix: `PERAWATAN PTLS BOP 09-02-2025.pdf` ➔ `PERAWATAN PTLS BOP 15-03-2026.pdf`.
    - Format teks bulan: `... 09 Februari 2025.pdf` ➔ `... 15 Maret 2026.pdf`.
- **Pembersihan Fisik Redaction via PyMuPDF (`fitz`)**:
  - Mengatasi masalah penumpukan teks layer jika hanya menggunakan `draw_rect`. Dengan `add_redact_annot` dan `apply_redactions()`, teks tanggal lama dipurging secara fisik dari layer PDF sebelum teks tanggal baru disisipkan.
  - Halaman 1: Penulisan tanggal ISO (`YYYY-MM-DD`) dengan font `Helvetica-Bold` ukuran `7.8pt`.
  - Halaman Foto: Penulisan tanggal Indonesia (`DD Bulan YYYY`) rata tengah persis di bawah `FOTO DOKUMENTASI` dengan font `Helvetica-Bold` ukuran `7.2pt`.
  - Watermark gambar foto tidak disentuh sehingga citra foto tetap 100% original.

### 2. Endpoint API Desktop di `run_desktop_webview.py`
- Menambahkan fungsi native multi-file picker `_pick_files_native()` menggunakan `tkinter.filedialog.askopenfilenames(multiple=True)` dan fallback `pywebview.create_file_dialog(allow_multiple=True)`.
- Mendaftarkan rute:
  - `POST /api/select-files`: Dialog pemilihan banyak berkas PDF sekaligus.
  - `POST /api/date-changer/scan`: Memindai daftar berkas atau direktori folder PDF, mengekstrak tanggal saat ini, keberadaan formulir Halaman 1 dan halaman foto.
  - `POST /api/date-changer/apply`: Menerapkan perubahan tanggal, opsi backup `.bak`, dan menamai ulang file secara in-place.
