## Pembuatan Standalone Executable Desktop (Windows .exe Non-Python/Non-Node)

- **Latar Belakang & Kebutuhan:** Pengguna menginginkan aplikasi web modern berbasis Next.js ini dapat didistribusikan dan langsung dijalankan pada komputer Windows lain yang **sama sekali tidak memiliki Python maupun Node.js** terinstal (*zero prerequisite*).
- **Arsitektur Distribusi Standalone:**
  1. **Runtime Node.js Portabel (`bin/node.exe`):** Menempatkan biner mandiri `node.exe` (v24.16.0) di folder `bin/` untuk mengeksekusi server produksi Next.js 14 tanpa bergantung pada PATH sistem.
  2. **Unified Python Engine (`scripts/python_engine.py`):** Membuat modul dispatcher tunggal yang mengimpor seluruh 14 skrip pipeline dan ekspor (`export_pdf_foto`, `scheduler`, `edit_timemark_ide1`, `merge_pdf_foto`, `audit_and_correct_personnel`, `export_tablo_excel`, `export_dinasan_excel`, dll.).
  3. **Kompilasi PyInstaller Python Engine (`bin/python_engine/python_engine.exe`):**
     - Dibuat menggunakan mode `--onedir` agar start-up proses instan (~50ms) tanpa overhead dekompresi `%TEMP%` berulang pada setiap pemanggilan skrip.
     - Seluruh C-extensions binary (`fitz` PyMuPDF, `pdfplumber`, `numpy`, `PIL` Pillow, `openpyxl`) terbundel utuh dan stabil.
  4. **Dynamic Engine Adapter (`web/src/lib/python-runner.ts`):**
     - Fungsi `spawnPython(scriptName, args, options)` otomatis mendeteksi keberadaan `bin/python_engine/python_engine.exe`.
     - Bila ada, pemanggilan diarahkan ke `python_engine.exe <scriptName> <args>`.
     - Bila tidak ada (lingkungan dev), otomatis fallback ke `python -u scripts/<scriptName>.py <args>`.
